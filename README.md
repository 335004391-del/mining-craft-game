# ⛏️ 合成挖矿 (Mining Craft)

一款**单文件网页放置+合成 Roguelike 游戏**，灵感来自《流放之路》(Path of Exile) 的多维属性机制 + 4399 经典挖矿玩法。

打开 `mining-craft.html` 双击即可玩，**单文件、零依赖、移动端优先**。

---

## 🎮 核心循环

1. ⛏️ **挖矿** —— 选一个矿脉，鼠标点挖（或开自动挖矿）
2. 💎 **掉落** —— 获得矿石（按等级）+ 16 阶宝石（普通→创世）
3. 🔨 **合成** —— 1 宝石 + 1 矿石 → 生成一把镐子
4. 📈 **升级** —— 用金币升级 8 条强化路线
5. 🔁 **滚雪球** —— 好镐子挖更好的料，做更强的镐子

## 🏔️ 180 级矿脉（18 种 × 10 阶循环）

指数级难度（每级防御 ×3.35），从 🟫 碎石坡到 💀 亡灵矿脉。每 10 级映射回基础矿脉+强化后缀（🟫碎石坡 → 🟫碎石坡+1 → ... → 🟫碎石坡+9 → ⚫铁矿脉）。
- 累计挖出该矿目标数量的矿石
- 镐子对当前矿脉效率 ≥ 90%
- → **自动解锁下一矿脉**

## ⚔️ 镐子 6 维属性（PoE 风格）

| 属性 | 作用 |
|---|---|
| ⚔️ 物理攻击 | 基础攻击 |
| 🎯 暴击率 | 触发暴击概率 |
| 💥 暴击伤害 | 暴击时伤害倍率 |
| ⚡ 攻击速度 | 攻速（次/秒） |
| 💎 宝石加成 | 宝石相关加成 |
| 🪨 矿石加成 | 矿石相关加成 |

合成时攻击浮动 **0.1× ~ 10×**（对数均匀分布），随机性强。

## 🛡️ 矿脉 6 维防御

护甲、格挡、闪避、抗性、攻速惩罚——每种矿脉有独特的"风格"（铁矿厚护甲、水晶高闪避、龙晶格挡+护甲、烈焰超高抗性...）

## ✨ 7 条稀有词缀

合成时小概率追加：**锋利/迅捷/精准/重量级/完美/宝石之心/矿石之魂**

## 👑 8 条升级路线

**基础 4 条**：
- 🔧 强化合成（攻击倍率）
- 🍀 提升掉落（掉宝率）
- 💎 强化宝石（暴击/宝石加成）
- 🪨 强化矿石（攻速/矿石加成）

**打造人员 4 条**（影响合成品质）：
- 👑 **名望**（词缀率 +0.5%/级，抬升攻击下限）
- 🔥 **锻造**（连质量浮动收窄）
- 🌟 **名将出品**（高 mult 概率 +2%/级，词缀数 +1）
- 🍀 **运气**（连质量上限突破 100）

## 🏷️ PoE 风格自动命名

每把镐子根据属性自动起名，例如：
`毁天·创世镐·神铸`、`锋利·苍穹镐·精工`、`破旧·破岩镐·初生`

## 📊 数值大数字

使用标准大数缩写 K / M / B / T / Qa / Qi / Sx / Sp / Oc / No / Dc + 科学计数法兜底。

## 💾 存档

`localStorage` 自动存档 + **离线结算**（最长 8 小时）。

---

## 🎯 操作

- 挖矿：底部「⛏️ 挖矿」按钮
- 合成：底部「🔨 合成」选批量 1/10/100
- 仓库：底部「🎒 仓库」看/换/卖镐子
- 升级：底部「📈 升级」买 8 种强化
